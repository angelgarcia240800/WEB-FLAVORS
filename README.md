# 🍓 WEB-FLAVORS

Sitio web oficial de **Batidos Flavors** — Batidos artesanales a base de frutas naturales, yogurt y postres caseros en Quíbor, estado Lara.

- **Alojamiento:** GitHub Pages
- **Despliegue Continuo (CI/CD):** Cada cambio en la carpeta `web/` en la rama `main` se publica automáticamente.

---

## 🗂️ Estructura del Repositorio

```text
WEB-FLAVORS/
├── .github/workflows/   # Automatización CI/CD con GitHub Pages
├── web/                 # Código fuente del sitio web (HTML, CSS, Assets)
├── CHANGELOG.md         # Historial oficial de versiones y cambios
└── README.md            # Información general del repositorio
```
